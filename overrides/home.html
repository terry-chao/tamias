Tamias

大模型看得动，几何改得动。

一个把 BIM 大模型查看 与 参数化几何编辑 放进同一个桌面应用的几何内核： Qt 做壳，自研 RHI 跑 Vulkan / OpenGL，OCCT 提供 BRep，IfcOpenShell 提供 IFC 语义， 中间用 特征树 与 分层场景图 串成一条链路。

功能

从「看得懂」到「改得动」的八件事

查看、编辑、业务语义、渲染、扩展各自分层，互相之间只走稳定的边界：语义树与渲染场景图用 ID 关联， 几何统一走几何边界（IShapeOps），编辑一律是可撤销命令。

参数化编辑内核

几何的源头是「参数 + 依赖」的特征树：改参数 → 求值重算 → 重新渲染。 BRep 与三角网都只是可重算的缓存，不是真相。

BIM 业务层

墙梁板柱、轴网、楼层与门窗宿主单独一层：墙-墙转角自动斜接，开窗改洞会通知墙体重造型， 语义树本身只记父子关系。

大模型查看

语义树与渲染场景图分离：空间索引做点选 / 框选，视锥剔除、LOD 与合批 / instancing 让超大模型也能流畅转、选、剖切。

空间索引

自研 RHI 双后端

自己的渲染硬件接口：Vulkan 为主、OpenGL 为副并在独立线程跑文档；启动探测、失败降级、 驱动块名单，GPU 不合适也不会打不开软件。

C# 插件与脚本

C++ 内核不动，扩展写在托管侧：约定目录里放 main.cs 或 .dll 即热加载， 可挂 Ribbon 命令、弹宿主对话框、在视口取输入；控制台能直接敲 C#。

插件与 SDK

通用编辑与撤销

移动 / 复制 / 旋转 / 镜像 / 阵列都是「选择集 → 一条命令」，全部进撤销栈； 批量阵列按轴线框选，落点多也能一次算完。

通用编辑

工作格式与交换格式分开

.tdoc 存语义树 + 特征树，是编辑态；IFC / STEP / glTF 只是进出口。 .trscn 是烤好的渲染快照，用来复现问题与跑渲染测试。

渲染快照

工作流

一条链路：进得来、看得清、改得动、交得出

外部格式只是端口，编辑永远发生在内部 Document 上——打开 IFC 翻译进内部结构后， 原文件就可以放下了。

  1. 1 · 导入

    打开 IFC / STEP / IGES / BREP / OBJ / GLB，或把 PDF / DXF / DWF 图纸铺进视口当底图。

  2. 2 · 查看

    语义树看层级，属性面板看 Pset，空间索引做点选 / 框选，超大模型靠剔除与 LOD 保持帧率。

  3. 3 · 编辑

    参数化改特征树（改参数 → 重算 → 渲染），或对选择集做移动 / 复制 / 镜像 / 阵列；都是可撤销命令。

  4. 4 · 交付

    导出 IFC / STEP / glTF，或继续存 .tdoc；要复现问题就存一份 .trscn 快照。

  • 进 IFCSTEPIGESBREPOBJGLB
  • 编辑态 .tdoc
  • 出 IFCSTEPglTF.trscn 快照

架构

六层，各管一件事

每一层都有独立的文档与测试。想深挖哪一层，直接点进去。

01 Qt 客户端src/app 窗口、三维视口、属性面板、大纲树与工具带；几何真相不在这层。 02 插件 / 脚本宿主src/plugin C# 扩展与命令控制台，挂在壳上；编辑仍走已有命令。 03 BIM 业务层src/bim 楼层、轴网、墙梁板柱、门窗宿主与关联关系 —— 建筑规则都在这。 04 场景图src/engine/document 语义树：层级、变换、包围盒缓存、IFC 属性与材质引用。 05 造型src/engine/modeling 特征树 · 求值器 · 几何边界（IShapeOps）：OCCT 与 IfcOpenShell。 06 渲染src/engine/render draw list、RHI（Vulkan / OpenGL / WebGPU）、视锥剔除、合批与 LOD。

为什么查看看得动

语义树与渲染场景图分离，用稳定 ID 关联：一侧管撤销、序列化、属性面板，另一侧管合批、LOD、裁剪与实例化。

为什么编辑敢下手

几何的真相是特征树（参数 + 依赖）；BRep 与三角网是缓存。任何编辑都封装成一条可撤销命令。

为什么能扩展

C++ 内核保持不动，扩展写托管侧；宿主 API 是一份稳定的面，插件可以随版本升级而不重写内核。

快速开始

三条命令，把源码跑起来

Windows 需要 Visual Studio 2022/2026、Qt 6、Vulkan SDK、vcpkg 与 CMake 3.24+； 首次配置会从源码编译 OCCT，等 1–2 小时是正常的。

PowerShell 
$env:VCPKG_ROOT = 'C:\dev\vcpkg'
$env:VULKAN_SDK = 'C:\VulkanSDK\<version>'

cmake --preset msvc
cmake --build --preset relwithdebinfo --parallel
& .\build\bin\RelWithDebInfo\tamias.exe
