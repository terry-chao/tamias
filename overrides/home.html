02 WORKFLOW

进得来，
看得清，改得动，
交得出。

外部格式只是端口，编辑永远发生在内部 Document 上。 打开 IFC、翻译进内部结构之后，原文件就可以放下了。

文档与场景
  1. 01

    导入

    打开 IFC / STEP / IGES / BREP / OBJ / GLB，或把 PDF / DXF / DWF 图纸铺进视口当底图。

  2. 02

    查看

    语义树看层级，属性面板看 Pset，空间索引做点选 / 框选；超大模型靠剔除与 LOD 保持帧率。

  3. 03

    编辑

    参数化改特征树，或对选择集做移动 / 复制 / 镜像 / 阵列；全部是可撤销命令。

  4. 04

    交付

    导出 IFC / STEP / glTF，或继续存 .tdoc；要复现问题就留一份 .trscn 快照。

进 IFCSTEPIGES BREPOBJGLB → .tdoc → 出 IFCSTEPglTF .trscn

04 DESIGN NOTES

为什么它敢接大模型，
也敢让人下手。

01

为什么查看看得动

语义树与渲染场景图分离，用稳定 ID 关联：一侧管撤销、序列化、属性面板， 另一侧管合批、LOD、裁剪与实例化。两边可以各自演进。

02

为什么编辑敢下手

几何的真相是特征树（参数 + 依赖）；BRep 与三角网是缓存。 任何编辑都封装成一条可撤销命令，失败也不会留下半个模型。

03

为什么能扩展

C++ 内核保持不动，扩展写托管侧；宿主 API 是一份稳定的面。 插件跟着版本升级，不用重写内核。

06 QUICKSTART

三条命令，
把源码跑起来。

Windows 需要 Visual Studio 2022/2026、Qt 6、Vulkan SDK、vcpkg 与 CMake 3.24+。 首次配置会从源码编译 OCCT，等 1–2 小时是正常的。

PowerShell 
$env:VCPKG_ROOT = 'C:\dev\vcpkg'
$env:VULKAN_SDK = 'C:\VulkanSDK\<version>'

cmake --preset msvc
cmake --build --preset relwithdebinfo --parallel
& .\build\bin\RelWithDebInfo\tamias.exe
